## [1.0.0] - 2026-07-02

### Added

- Ejemplos de programación orientada a objetos en seis lenguajes: Python
  (`ventilador.py`), JavaScript (`tiquete.js`), Ruby (`servicio.rb`), Java
  (`plato.java`), Dart (`avion.dart`) y Swift (`carro.swift`).
- Estructura de documentación en `docs/` (índice, convenciones, decisiones/ADR,
  roadmap y glosario) adoptada desde la plantilla `project-starter-template-es`.
- Archivos de gobernanza: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`,
  `CHANGELOG.md`.
- Plantillas de issues y Pull Requests, `FUNDING.yml`, Dependabot y labeler en
  `.github/`.
- `.editorconfig` y `.gitignore` para higiene del repositorio.

### Changed

- `README.md` reescrito con tabla de contenidos, badges e índice de documentación.
