# Glosario

Vocabulario compartido del proyecto. Definiciones cortas y sin ambigüedad para que
todo el mundo use los términos de la misma forma.

| Término                | Definición                                                                                                       |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Concepto               | Idea o principio de programación (clases, herencia, encapsulamiento…) que puede expresarse en cualquier lenguaje. |
| Ejemplo                | Archivo autocontenido y ejecutable que ilustra un concepto en un lenguaje específico.                            |
| Lenguaje idiomático    | Forma "natural" de escribir código respetando las convenciones propias de cada lenguaje.                         |
| Paradigma              | Estilo de programación (orientado a objetos, funcional, imperativo…) que agrupa un conjunto de conceptos.        |
| Programación agnóstica | Enfoque que separa los **conceptos** de programación del **lenguaje** concreto en que se implementan.            |

> Convención: ordena los términos alfabéticamente y enlaza al documento donde se
> detalla cada concepto cuando aplique.
