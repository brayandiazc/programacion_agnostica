# Convenciones

Esta carpeta documenta **cómo trabajamos** en Programación Agnóstica: reglas y
estándares transversales para aportar y mantener los ejemplos de código.

## Convenciones incluidas

| Convención                               | Tema                                       |
| ---------------------------------------- | ------------------------------------------ |
| [quality-tooling.md](quality-tooling.md) | Formato y herramientas por lenguaje        |
| [testing.md](testing.md)                 | Cómo verificar que los ejemplos funcionan  |

## Agregar una convención

Copia [`_template.md`](_template.md), renómbralo en `kebab-case` y documenta el
nuevo tema. Añádelo a la tabla de arriba.

## Convenciones adicionales opcionales

No se incluyen por defecto; créalas con `_template.md` si el proyecto las necesita
(por ejemplo: guía de estilo por lenguaje, criterios para elegir qué concepto
documentar, plantilla de estructura de cada ejemplo).
